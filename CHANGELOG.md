## 1.0.0

- First Flutter release: Android, iOS, macOS, Windows, Linux (web is not supported by design).
- Managed and custom server modes; every request sends `platform`.
- Default responsive blocking overlay + update bottom sheet, with custom builders.
- `LaterBehavior.dismiss` / `LaterBehavior.snooze` option.
- Server-provided `title` (max 100) and `message` (max 500).
- `onUpdateCheckComplete` listener and `results` stream.
